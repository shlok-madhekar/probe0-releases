# Probe0 releases

Installers for the Probe0 beta. Get them from [probe0.xyz/betaInstall](https://www.probe0.xyz/betaInstall).

The beta builds are not yet signed:

- **macOS:** after the first open, go to System Settings, then Privacy & Security, and click **Open Anyway**.
- **Windows:** if SmartScreen stops the installer, click **More info**, then **Run anyway**.
